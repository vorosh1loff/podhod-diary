# podhod-diary
Подход — офлайн-дневник силовых тренировок

- Недельная шкала показывает сумму нагрузки по мышцам за день. Нажмите на день для разбивки по группам.
- В записи календаря нажмите на число подходов, чтобы открыть список и действия с упражнением.
- Название и заметка связанного упражнения общие для каталога, шаблонов и записей календаря. Если упражнение удалено из каталога, запись показывает сохранённые название и заметку.
